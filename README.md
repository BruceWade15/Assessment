# Assessment Developer

A form for briefing a new assessment app. It captures the name, purpose, methodology, number and type of questions, result categories and the technical needs, then produces a written spec you can copy.

**Live:** https://brucewade15.github.io/Assessment/

## How it works

- One self contained `index.html`. There is no build step and nothing to install.
- To run it on your own computer, open `index.html` in a browser.
- Hosted on GitHub Pages from this repo, so a push to the main branch updates the live site.
