# Assessment Developer

A guided brief for a new assessment app. Answer the questions and it writes the prompts that build the app with Claude.

**Version 2 (live):** https://brucewade15.github.io/Assessment/v2/
**Classic version:** https://brucewade15.github.io/Assessment/

## Version 2

An eight step wizard:

1. About you
2. The assessment
3. Questions (type your own, or let Claude draft them for approval)
4. Scoring and results (score bands, headings, descriptions, next step button)
5. Details to collect (with consent line; database, email and CRM options marked "coming later")
6. Look and feel (logo, colours, font, tone, spelling)
7. Where it will live (GitHub Pages, WordPress or own computer)
8. Your prompts: build, check, change, publish, update, and a plain chat version

The brief saves in the browser as you go. It can also be saved to a file and opened again. "Load example" fills in the Work Place Stress Assessment.

## How it works

- Each version is one self contained `index.html`. There is no build step and nothing to install.
- To run it on your own computer, open `index.html` or `v2/index.html` in a browser.
- Hosted on GitHub Pages from this repo, so a push to the main branch updates the live site.
